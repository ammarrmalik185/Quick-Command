# Quick Command privacy policy — draft for publisher review

Applies to Quick Command version 1.0.0.

Publisher: ParadoXSoftware.

Quick Command stores your custom PowerShell commands locally in your Windows user profile. The app itself does not collect or transmit analytics, account information, command content, or usage history. It has no account system or built-in advertising.

Quick Command executes commands you choose and scripts you write. Those scripts and external programs may read files, access the network, or send information according to their own behavior and policies. Review commands before running them.

The Store distribution and Windows platform are governed by Microsoft's policies. External editors and other tools are governed by their providers' policies.

You can edit or remove your local command file at %LOCALAPPDATA%\QuickCommand\commands.ps1. Keep a backup if you want to retain it. Windows packaging may redirect local app data into the app's package storage; qc edit opens the actual file used by the app.

Before publishing this policy, the publisher must add an effective date, support/privacy contact, and publicly accessible policy URL, and confirm the publisher name. Review this draft against the final distributed build and any future changes.
